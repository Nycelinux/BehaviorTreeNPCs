# Behaviour Tree NPC

## Steuerung

| Taste                                | Funktion                           |
| ------------------------------------ | ---------------------------------- |
| **W, A, S, D**                       | Charakter bewegen                  |
| **Leertaste**                        | Springen                           |
| **E**                                | Mit Objekten und NPCs interagieren |
| **J**                                | Questliste öffnen                  |
| **Pfeil nach oben**                  | Nach oben schauen                  |
| **Pfeil nach unten**                 | Nach unten schauen                 |
| **Linke Maustaste / Touchpad-Klick** | Angreifen                          |
| **ESC**                              | Spiel pausieren                    |

## Bekannte Probleme

### Pause-Menü

Die Pause-Funktion ist derzeit noch nicht vollständig funktionsfähig. Der Pause-Button funktioniert aktuell nicht korrekt, da mehrere UI-Panels übereinander liegen.

### Angriffssystem

Angriffe werden über die linke Maustaste ausgelöst. Die Funktion wurde mit dem Touchpad getestet und sollte auch mit einer normalen Maus funktionieren.
